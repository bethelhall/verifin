# Included evaluation inputs

These files support the three offline reproduction notebooks: benchmark
questions, evaluator-only targets, scoring-review annotations, and the exact
reviewed documents/XML required by their checksum checks.

The full document corpora for new TADQA/XBRLFiling model inference are external.
See [generation requirements](../docs/GENERATION.md) and
[data/provenance](../docs/DATA_AND_PROVENANCE.md).
